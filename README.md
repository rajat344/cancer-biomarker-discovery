# Cancer Biomarker Discovery

A computational biology project for identifying candidate cancer
biomarkers from gene-expression data.

## Objective

This project analyzes gene-expression differences between cancer
and normal tissue to identify significantly altered genes,
investigate their biological pathways, and evaluate candidate
biomarkers computationally.

## Planned Workflow

1. Data acquisition
2. Data quality control
3. Exploratory data analysis
4. Differential gene expression
5. Multiple-testing correction
6. Pathway enrichment
7. Candidate biomarker identification
8. ROC/AUC evaluation
9. Machine-learning classification
10. Interactive visualization
